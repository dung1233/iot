## Mô tả
Dự án này tổng hợp các ứng dụng mẫu mà công ty đang sử dụng, bao gồm:
- Xây dựng RESTful API
- Truy cập dữ liệu với MongoDB
- Truyền nhận dữ liệu real-time giữa các services với SignalR
- Cache dữ liệu bằng RAM (Dictionary) và Redis
- Một ứng dụng tổng hợp tích hợp tất cả các công nghệ trên

## Cấu trúc thư mục

- `RESTful` – Ứng dụng API theo chuẩn RESTful
- `ConnectionMongodb` – Ứng dụng truy cập và thao tác với MongoDB
- `SignalR` – Ứng dụng giao tiếp real-time giữa các service
- `CacheWithRAM` – Cache dữ liệu trên RAM (Dictionary)
- `RedisCacheDemo` – Cache dữ liệu sử dụng Redis
- `TTS` – Ứng dụng tổng hợp tất cả các chức năng trên
